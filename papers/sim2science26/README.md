# Sim2Science 2026 Paper Package

This package uses the official NeurIPS 2026 `dblblindworkshop` template with `Sim2Science` as the workshop title. The technical paper occupies five pages; references and the completed NeurIPS checklist follow outside that limit.

Compile with:

```bash
TECTONIC_CACHE_DIR="../../.cache/tectonic" tectonic main.tex
```

The paper is deliberately different from the AI4S version. Its central claim concerns decision fidelity when an imperfect CFD simulator serves as both teacher and verifier. Runtime remains supporting evidence rather than the headline contribution.
