# Sim2Science 2026 Paper Package

This package uses the unmodified official NeurIPS 2026 `dblblindworkshop`
template with `Sim2Science` as the workshop title. The generic submission
notice on page 1 is generated by that official double-blind style; it should
not be manually replaced. The technical paper occupies five pages; references
and the completed NeurIPS checklist follow outside that limit.

Compile with:

```bash
TECTONIC_CACHE_DIR="../../.cache/tectonic" tectonic main.tex
```

The paper is deliberately different from the AI4S version. Its central claim concerns decision fidelity when an imperfect CFD simulator serves as both teacher and verifier. Runtime remains supporting evidence rather than the headline contribution.

## Before Submission

- Rewrite the draft substantively in the authors' own voice; it is an AI-assisted starting manuscript, not a submission-ready substitute for human authorship.
- Attach the sanitized sub-100 MB artifact ZIP and add an anonymous URL for the
  full CFD data.
- Recheck every checklist response after the artifact is posted.
- Confirm that all three seeds, final-test statistics, and selected-design grid
  checks in the PDF match the revised result CSV files.
- Confirm the reciprocal-reviewer requirement and list every author at initial submission.
- Run a final citation, similarity, anonymity, and PDF check.
